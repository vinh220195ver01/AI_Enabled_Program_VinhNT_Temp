# exercises/

One folder per exercise: `exercises/<exNN>-<short-name>/` (for example `ex01-fizzbuzz`).

Each folder holds:
- `BRIEF.md` — the task and its "Done when" criteria (start from `_template/BRIEF.md`)
- your solution files and tests

When done, follow the last step of `.claude/skills/exercise-agent/SKILL.md`:
`/submit-exercise <exercise name>`, where the exercise name is the folder name
(for example `/submit-exercise ex01-fizzbuzz`).
